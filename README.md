# 🌟 Virtual Studio - E-commerce y Servicios para Eventos en Bolivia

**Virtual Studio** es una plataforma web moderna y completa orientada al alquiler de equipos, contratación de servicios integrales y gestión de eventos (matrimonios, 15 años, cumpleaños, aniversarios y eventos corporativos) con cobertura en toda Bolivia.

---

## 🚀 Características Principales

*   **Catálogo Interactivo de Servicios y Equipos:** Alquiler de estructuras, iluminación, sonido y mobiliario tanto de forma individual como en paquetes personalizados.
*   **Cotizador Dinámico:** Sistema inteligente que permite a los clientes calcular presupuestos en tiempo real según los requerimientos de su evento.
*   **Gestión de Reservas:** Registro y administración de solicitudes de clientes adaptadas al mercado boliviano.
*   **Panel de Administración:** Control total de inventarios, cotizaciones y estados de reservas.
*   **Diseño Responsivo (Mobile-First):** Interfaz adaptada perfectamente a smartphones, tablets y computadoras.

---

## 🛠️ Tecnologías Utilizadas

Este proyecto ha sido desarrollado utilizando tecnologías web modernas de alto rendimiento:

*   **Frontend:**
    *   **HTML5** y **CSS3**
    *   **Tailwind CSS** (Diseño visual y componentes responsivos)
    *   **JavaScript (ES6+)** (Lógica de interacción y dinamismo del e-commerce)
*   **Backend & Base de Datos:**
    *   **Supabase** (Base de datos relacional PostgreSQL, autenticación y políticas de seguridad RLS)
*   **Despliegue y Control de Versiones:**
    *   **Git & GitHub**
    *   **Vercel** (Hosting y despliegue continuo)
